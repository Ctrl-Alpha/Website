How to Add a New MoM

  1. Create a new file in the _moms directory
  2. Name it: YYYY-MM-DD-meeting-title.md
  3. Add the front matter with meeting details
  4. Write the meeting content in Markdown
  5. Commit and push - it will appear automatically!

Template available in the repository for easy copying.
