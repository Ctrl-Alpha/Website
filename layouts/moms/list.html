How to Add a New MoM

  1. Create a new file in the content/moms directory
  2. Name it: YYYY-MM-DD-meeting-title.md
  3. Copy the template from archetypes/moms.md
  4. Fill in the front matter with meeting details
  5. Write the meeting content in Markdown
  6. Commit and push - it will appear automatically!
